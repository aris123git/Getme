# Getme

Application web de rencontres de proximité (PWA) — carte GPS, chat, profil, paiements SMS (Orange Money / Wave / Moov).

## Stack

- Frontend : HTML / CSS / JS modules + Leaflet
- Backend data : Supabase (Auth, Postgres, Realtime, Storage)
- Hosting : Netlify (`_redirects`, `_headers`, functions SMS)

## Démarrage local

Ouvre `index.html` via un serveur local (modules ES), ou déploie sur Netlify.
